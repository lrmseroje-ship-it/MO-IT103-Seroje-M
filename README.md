# MotorPH Employee Payroll System

## Overview

The MotorPH Employee Payroll System is a Java-based desktop application developed as part of the MO-IT103 course requirements. The system allows users to search employee records and process payroll based on employee attendance, selected month, and pay coverage period.

## Features

* Search employees using Employee Number
* Display employee information automatically
* Process payroll for:

  * 1st Cutoff (1–15)
  * 2nd Cutoff (16–31)
  * Whole Month
* Calculate employee payroll based on attendance records
* Generate payroll summaries
* User-friendly graphical user interface (GUI) using Java Swing

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Irmseroje-ship-it/MO-IT103-Seroje-M.git
```

2. Open the project in Visual Studio Code.

3. Ensure Java JDK is installed.

4. Run:

```bash
Main.java
```

5. The MotorPH Employee Payroll System window will launch.

## Usage

1. Enter an Employee Number.
2. Click **Search**.
3. Verify the employee information displayed.
4. Select the Month.
5. Select the Pay Coverage period.
6. Click **Process Payroll**.
7. Review the payroll summary generated by the system.
